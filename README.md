# Public host infrastructure

Published at https://hazelejeong.github.io/ from the dedicated repository
`hazelejeong/hazelejeong.github.io`.

The root provides site ownership verification files, the effective host-level
robots.txt, a sitemap, and links to the existing Sajutokki project site.
Do not remove the Google or Naver verification files. Product URLs and their
canonical addresses remain under `/sajutokki-public/`.

The root index is intentionally noindex. The sitemap lists product-site URLs.
When adding other projects, preserve their existing paths and crawler policies.
